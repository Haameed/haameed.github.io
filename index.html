01 / About

I like infrastructure that runs
itself and tells you when it can't.

My first job was in a network operations center for the National Iranian Oil Company, watching dashboards for more than 4,000 fuel stations across the country. That's where I picked up two habits I still have: I want to know a service is in trouble before someone calls, and I don't like fixing the same thing by hand twice.

After that I ran Linux and virtualization platforms at an ISP, a telecom operator, a ride-hailing company and a digital bank. At Snapp I looked after about 70 bare-metal hosts and over 700 VMs on KVM and OpenNebula, mostly through Ansible, Terraform and GitLab CI. 03 / Open source

Things I've built and published

Haameed / f5_bigip_exporter

F5 BIG-IP Prometheus Exporter

I couldn't find an exporter that covered what we needed from our F5 load balancers, so I wrote one. It uses the iControl REST API and follows the multi-target /probe pattern, so a single instance can scrape any number of BIG-IP devices with no agent on the box.

  • Virtual servers, pools, nodes, TMM, HA state
  • SSL certificate expiry and TLS version usage
  • Collectors run concurrently in goroutines
  • Token caching: one login under concurrent scrapes
  • Hardware sensors, skipped cleanly on VE
  • Grafana dashboard and alert rules included

Haameed / f5_f5os_exporter

F5OS Exporter

After the BIG-IP exporter came out, the question I got most was "what about F5OS?" This is the answer. It covers rSeries and VELOS through the OpenConfig-based REST API, including CPU, disks, PSUs, interfaces, LACP and licensing.

GoOpenConfigGoReleaser
Haameed / opennebula-dynamic-inventory

OpenNebula Inventory for Ansible

An Ansible inventory plugin that reads running VMs from one or more OpenNebula clusters and groups them by name, label or attribute (SSH port, for example). It works with the CLI, AWX and GitLab CI.
